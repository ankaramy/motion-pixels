# Final dataset images

31 images, named by site and document type.

- tracking: selected full-resolution frozen frames for all seven recordings.
- heatmap: retained final bottleneck-density stills for all seven recordings.
- speedmap: retained final speed-population stills for all seven recordings.
- lingerzones: filtered_250m linger-zone exports for all seven recordings.
- predictionrollout: exact H400/d600 site-plan style specified by the user, available for Placa Catalunya, Placa Espanya, and Esplanade Espanya.

No matching H400/d600 plan exports were found for Placa Montjuic, Red Bridge, or either Montjuic stair recording. Other prediction styles are excluded.

Sources and frame details are in sources.csv. H400/d600 predictions are illustrative 600-step MODEL_X rollouts from the H400 checkpoint. Original source images are unchanged.
